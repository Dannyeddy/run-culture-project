# Zen Run Process Portfolio

This repository hosts the published process portfolio for the **Zen Run** project in **CPT208 Human-Centric Computing**.

## Live Site

[View the portfolio here](https://dannyeddy.github.io/run-culture-project/)

## About This Repository

This is the static-site deployment repository for the final portfolio presentation. It contains the built files used for GitHub Pages publishing rather than the full development workspace.

## Portfolio Structure

The portfolio presents the project through the following sections:

- Motivation & Research
- User Requirements
- Ideation & Alternatives
- Technical Implementation
- Evaluation & Reflection

## Project Focus

Zen Run explores how a cultural running experience can combine:

- route-based exercise
- local heritage content
- companion interaction
- post-run reflection and rewards

## Notes

- The portfolio is designed as a continuous case-study website.
